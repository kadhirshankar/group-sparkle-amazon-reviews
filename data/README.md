# Data

We use [Amazon Fine Food Reviews](https://www.kaggle.com/datasets/snap/amazon-fine-food-reviews).

The project sample is 50,000 reviews with seed 49, generated using the instructor's sampling script. Save the sample in this folder as `data/group_sample_seed49.csv` (the name `BOW_TF-IDF.py` reads). The original dataset, the sample, and any generated CSVs are excluded from GitHub by `.gitignore`.

Record the sampling command and any cleaning steps with the analysis so everyone can reproduce the same sample.
